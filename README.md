# STM32 智能风扇温控系统

> 基于 STM32F103C8T6 的环境温度监测 + 自动风扇控制项目
> NTC 热敏电阻测温 → OLED 实时显示 → 超阈值自动开风扇（滞回控制）+ LED 闪烁报警

---

## 📖 项目简介

这是一个面向 STM32 入门者的综合练习项目：

- 用 **NTC 热敏电阻** 采集环境温度（ADC + B 值公式换算）
- **OLED 屏幕**实时显示温度和风扇状态
- 温度超过 **30℃** 自动启动直流电机（模拟风扇），降到 **29℃** 以下停止（滞回控制，避免临界频繁启停）
- 风扇运行时 **LED 非阻塞闪烁**
- 所有参数集中管理在 `config.h`，方便修改和扩展

---

## ✨ 功能特性

- [x] NTC 热敏电阻温度采集（ADC 12 位分辨率）
- [x] B 值公式温度换算，支持小数显示
- [x] OLED 实时显示温度（℃）与风扇状态（ON/OFF）
- [x] **滞回控制**：高温启动 / 低温停止，不抖动
- [x] TB6612 直流电机驱动（PWM 调速）
- [x] **非阻塞 LED 闪烁**（定时器节拍，不卡死主循环）
- [x] 参数集中管理（`config.h`）
- [x] 模块化设计（温度 / 电机 / LED / 显示 / 时基 各自独立）

## 🚀 快速开始

### 环境要求
- Keil MDK5 + STM32F1xx 器件包
- ST-Link / J-Link 下载器

### 步骤
1. 克隆本仓库：
   ```bash
   git clone <你的仓库地址>
   ```
2. 用 Keil 打开 `project.uvprojx`
3. 根据你的实际接线，修改 `System/config.h` 里的引脚定义和参数
4. 编译（Build），通过 ST-Link 下载到板子
5. 上电即可运行

### ⚙️ 核心参数（在 `config.h` 中修改）

```c
#define TEMP_ON_THRESHOLD    30.0f    // 风扇启动温度
#define TEMP_OFF_THRESHOLD   29.0f    // 风扇停止温度
#define FAN_SPEED            50       // 风扇速度（0~100）
#define LED_BLINK_HALF_MS    500      // LED 闪烁半周期
```

## 🧠 工作原理

### 温度采集（B 值法）

NTC 热敏电阻和分压电阻组成分压电路，STM32 读分压点电压：

```
① ADC(0~4095) → 电压：  Vout = 3.3 × ADC / 4095
② 电压 → NTC 电阻：      R = 10000 × Vout / (3.3 − Vout)
③ 电阻 → 温度：          1/T = 1/298.15 + ln(R/10000)/3950
                        （T 减 273.15 得摄氏温度）
```

### 滞回控制（Hysteresis）

```
温度 ≥ 30℃ ──→ 风扇启动（ON）
温度 ≤ 29℃ ──→ 风扇停止（OFF）
中间区间（29~30℃）── 保持当前状态
```

这样温度在临界点附近波动时，风扇不会频繁启停。

### 非阻塞闪烁

不使用 `Delay_ms(500)` 阻塞等待，而是靠 TIM3 每 1ms 中断维护的 `TickCount`：
主循环每轮检查"距上次翻转是否到了 500ms"，到了才翻转 LED——**主循环永远不卡死**。
